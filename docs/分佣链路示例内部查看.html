分销比例规则说明

与「团长体系 · 分销比例配置」弹窗内容同步（V1–V3）

V1➡️V2➡️V3 可根据条件升级；一般满足以下所有条件即可自动升级：

  1. 直接邀请人数达标：需要被邀请人 30 天的收益大于等于 10 元（具体达标人数可在详情页查看）
  2. 30 天直推人数的总收益达标：需要直接邀请的用户数总收益达标（具体达标人数可在详情页查看）

1等级分佣权限总览

等级 用户关系分佣 团队关系分佣
V1 直邀 + 间邀（对下级 V1，无无限） ✗ 不适用（非团长）
V2 对 V1：直+间+∞；对 V2：直+间（无无限） 直属团 + 间属团（同级无无限团）
V3 对 V1：直+间+∞；对 V2/V3：直+间（无无限） 直属团 + 间属团 + 无限团（仅对下级 V2）

2用户关系分佣规则

用户关系分佣：V2、V3 对下级 V1、V2、V3 均可获得并配置「直邀 + 间邀」； 「无限」比例仅在针对下级 V1 时配置（V2/V3→V1）。 V1 对下级 V1 为直邀 + 间邀（无无限）。各分佣等级需分别配置不同下级目标等级的比例。
场景：V3 等级的用户关系分佣配置项
下级等级 直邀比例 间邀比例 无限比例 说明
V1 ✓ 配置 ✓ 配置 ✓ 配置（V2/V3→V1） 邀请下级 V1：直+间+∞
V2 ✓ 配置 ✓ 配置 ✗ 不配置 V3 邀 V2：直+间
V3 ✓ 配置 ✓ 配置 ✗ 不配置 V3 邀 V3：直+间

补充：针对下级 V2、V3 不配「无限」用户关系分佣；间邀比例仍须配置。

示例：H(V1) 出单链路中，G 为直邀、F 为间邀（V2/V3 均可参与直邀+间邀分佣）
…更高层← E(V2)← F(V2)← G(V1)← H(V1)← 出单
G(V1) 获得【直邀比例】（G 直接邀请了 H，同 V1 等级）
F(V2) 获得【间邀比例】（F 是 G 的上级，V2 高于 V1）
E 及以上：无用户关系分佣，超出 2 层截止

3团队关系分佣规则

V1 不是团长，无团队关系分佣。V2+ 按目标团长等级分别配置。 以团长节点跳数计算：第 1 跳=直属团；第 2 跳=间属团；≥3 跳=无限团（仅高等级对低等级）。
场景：V3 等级的团队关系分佣配置项
目标团长等级 直属团 间属团 无限团 说明
V1 — — 不适用（V1 非团长）
V2 ✓ 配置 ✓ 配置 ✓ 配置（V3>V2） 高等级对低等级团长，三项全配
V3 ✓ 配置 ✓ 配置 ✗ 不配置 同等级团长，仅直属+间属
示例：H(V1) 出单，F(V2) 是所属团长，团队分佣链路
A(V3)← B(V3)← C(V3)← D(V2)← E(V2)← F(V2)← H(V1)← 出单
E(V2) → 直属团（F 第 1 跳，同 V2 级）
D(V2) → 间属团（F 第 2 跳，同 V2 截止）
C(V3) → 无限团（F 第 3 跳，V3>V2 穿透，重置新起点）
B(V3) → 直属团（C 重置起点第 1 跳，同 V3 级）
A(V3) → 间属团（C 重置起点第 2 跳，同 V3 级截止）
