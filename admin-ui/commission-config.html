用户关系分佣规则
每个分佣等级需分别配置不同下级等级的比例。同等级只有直邀+间邀（2层）；高等级对低等级额外增加无限比例（第3层及以上，但前提是上级链路中都是同一个等级）。
场景：V3 等级的用户关系分佣配置项
下级等级直邀比例间邀比例无限比例说明
V1✓ 配置✓ 配置✓ 配置（V3>V1）高等级对低等级，三项全配
V2✓ 配置✓ 配置✓ 配置（V3>V2）高等级对低等级，三项全配
V3✓ 配置✓ 配置✗ 不配置同等级，仅直邀+间邀，截止

团队关系分佣规则
V1 不是团长，无团队关系分佣。V2+ 按目标团长等级分别配置。以团长节点跳数计算：第1跳=直属团；第2跳=间属团；≥3跳=无限团（仅高等级对低等级）。

出单分出总比例计算
最低分出比例 = 所有目标等级配置中，直邀比例的最大值（最少只触发一条直邀）。
最高分出比例 = 所有配置项（用户关系 + 团队关系）之和（全链路同时触发的极限情况）。
